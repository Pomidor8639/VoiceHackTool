## Возможности

- 5 голосовых пресетов:
  - 1. Аноним: многослойный сдвиг тона (-7.0 и -13.5 полутонов суб-гула), глубокий резонанс груди (135 Гц), срез верхних частот (3900 Гц) и ламповый перегруз (Tube Overdrive). Полная маскировка тембра реального голоса.
  - 2. Женский: плавный формантный сдвиг (+3.8 полутона) с фильтрацией низкого баса (170 Гц) и осветлением гармоник (2800 Гц).
  - 3. Ребенок: звонкий и естественный высокий голос (+6.0 полутонов) с обрезным фильтром 230 Гц и акцентом на верхах (3600 Гц).
  - 4. Демон: экстремально низкий рычащий тембр (-9.0 и -15.5 полутонов) с массивным овердрайвом.
  - 5. Пользовательский: гибкая ручная настройка параметров тембра под себя.

- Меню тонкой настройки голоса (клавиша C):
  - Точная регулировка питча от -18.0 до +18.0 полутонов.
  - Регулировка лампового перегруза (дисторшна) от 0% до 100%.
  - Усиление басового резонанса от 0 до +15 дБ.
  - Робо-модуляция (тремоло) от 0% до 100%.
  - Все параметры сохраняются автоматически в config.json.

- Мягкий кроссфейд при переключении:
  - Плавный переход между пресетами без щелчков, задержек и артефактов.

- Проверка звука микрофона в реальном времени:
  - При выборе микрофона отображается живая полоса уровня сигнала (VU meter), позволяя мгновенно убедиться в работе устройства до подтверждения выбора.

- Интеллектуальная фильтрация аудиоустройств:
  - Автоматическое скрытие дубликатов, системных псевдонимов (Primary Sound Driver, Переназначение, Стерео микшер) и драйверов WDM-KS. В меню отображаются только реальные подключенные физические микрофоны и виртуальные кабели.

- Встроенный предусилитель и шумоподавитель:
  - Входное усиление (x2.2) для тихих микрофонов.
  - Регулировка громкости на лету клавишами + и - (до 400%).
  - Адаптивный Noise Gate отсекает фоновые шумы и дыхание в паузах.

- Маршрутизация в виртуальный микрофон:
  - Перенаправление обработанного потока в виртуальный аудиокабель (VB-CABLE, Animaze Virtual Audio и др.), который затем выбирается в качестве микрофона в Discord, Telegram, CS2, Dota 2, OBS или других программах.

- Мониторинг в реальном времени:
  - Функция прослушивания собственного обработанного голоса в наушниках без задержек.

- Сохранение настроек в системе:
  - Параметры автоматически сохраняются в постоянную системную папку `%APPDATA%\VoicehackTool\config.json`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1` | Пресет Аноним |
| `2` | Пресет Женский |
| `3` | Пресет Ребенок |
| `4` | Пресет Демон |
| `5` | Пресет Пользовательский (Свой голос) |
| `C` | Меню настройки своего голоса (Питч, Дисторшн, Бас, Робот) |
| `V` | Циклическое переключение всех 5 пресетов |
| `+` / `-` | Регулировка выходной громкости (+20% / -20%) |
| `T` / `Пробел` | Включение / выключение эффекта (Bypass) |
| `M` | Заглушить микрофон (Mute) |
| `L` | Прослушивание себя в наушниках (Мониторинг) |
| `D` | Меню смены микрофона и устройства вывода |
| `Q` / `Esc` | Выход из программы |

## Требования

- Windows 10 / 11
- Python 3.10 или новее
- Виртуальный аудиодрайвер (один из вариантов):
  - VB-Audio Virtual Cable (бесплатный, рекомендуется)
  - Animaze Virtual Audio Driver
  - Voicemod Virtual Audio

## Установка и запуск

### Способ 1. Готовый архив (Без установки Python)

1. Перейдите на страницу [Релизов](https://github.com/Pomidor8639/VoiceHackTool/releases/tag/v1.0.0).
2. Скачайте архив `VoicehackTool-v1.0.0-windows.zip`.
3. Распакуйте в любую удобную папку и запустите `VoicehackTool.exe`.

### Способ 2. Запуск через Python

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Pomidor8639/VoiceHackTool.git
cd VoiceHackTool
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите программу:
```bash
python main.py
```

## Настройка виртуального микрофона

1. При первом запуске нажмите `D` и выберите:
   - Входное устройство: ваш физический микрофон.
   - Выходное устройство: виртуальный кабель (например, `CABLE Input` или `Speaker (Animaze Virtual Audio)`).
   - Устройство мониторинга: ваши наушники.
2. В Discord / Telegram / играх перейдите в настройки звука и в поле **Устройство ввода (Микрофон)** выберите соответствующий виртуальный микрофон:
   - `CABLE Output (VB-Audio Virtual Cable)` или `Microphone (Animaze Virtual Audio)`.

## Структура проекта

- `main.py` — точка входа, цикл приложения, обработка горячих клавиш и рендеринг терминального интерфейса.
- `dsp.py` — модуль цифровой обработки сигналов (гранулярный питч-шифтинг, биквадратные эквалайзеры, ламповый овердрайв, шумоподавитель, кроссфейдер).
- `audio_engine.py` — управление потоками PortAudio через sounddevice, фильтрация системных устройств, мониторинг, тестирование микрофона.
- `ui.py` — вывод стилизованного баннера и индикаторов уровней сигнала (VU meters).
- `config_manager.py` — сохранение и загрузка настроек устройств в AppData.
